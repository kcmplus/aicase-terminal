# 设备页 V6

根据用户提供的 `POPOMO-Kiosk-V6-static.zip` 调整终端视觉：青粉渐变背景、透明白色扫码卡、深青色打印卡、粉色进度条、大幅订单预览，以及订单／扫码指南弹窗。设备名称、编号、二维码、预览图和状态来自现有宿主数据，不使用稿件里的示例设备或假二维码。

设备页继续只读。新建／已有订单按钮打开扫码说明，确认到场和“立即打印”仍在手机 H5；没有接入稿件中的本机开印按钮或定时模拟状态。已出货仅表示宿主报告出货，不表示客户已取件；历史已出货记录在全部订单弹窗中展示，不作为当前取件提醒。

- 右上角设备状态与可选调试日志保留。
- 底部保留接口订单数与异常记录数，点击“本机订单”可滚动查看全部状态和编号。
- 弹窗在设备事件刷新时保持打开、滚动位置和控制按钮焦点，支持 Escape 关闭及键盘焦点循环。
- 不增加自动待机遮罩，主屏二维码持续可见；后台明确锁定或关闭手机入口时仍隐藏二维码。
- 共享样式用于供应商内嵌、Vite mock、后端直连和离线日志回放。

本地预览：`npm run dev` 后打开 `http://127.0.0.1:4180/?preview=1&scenario=printing&lang=zh-CN`。
可将 `scenario` 改为 `ready`、`queue`、`delivered`、`offline`、`locked` 或 `error` 查看不同状态。此入口为样例数据，不是实际设备。
