# 跳过供应商，直连自己的后端

在终端工程根目录执行：

```sh
npm run dev:direct
```

需要同级目录的 `aicase` 后端处于支持直连调试的版本（分支 `codex/direct-terminal-debug`），具备原有 Python 环境、本地数据库和模板素材。默认设备 `789`，商家 `351`。

它自动启动独立后端、手机 H5 和设备展示页：

- 设备页：`http://127.0.0.1:4182/direct.html?lang=zh-CN`
- 手机页：启动日志打印电脑的局域网地址，端口 `4174`；手机与电脑连同一网络，也可扫设备页二维码。
- 后端：本机 `8001` 端口。

手机下单、上传图片和“立即打印”都经过自己的后端，设备页读取真实订单。硬件使用模拟进度，确认后约 25 秒完成；右上角设备状态和调试日志仍可使用。订单和模拟状态保存在独立数据库，刷新、新开设备页或重新启动不会消失。

```sh
# 指定工程目录、设备，以及手机能访问的电脑地址
npm run dev:direct -- --backend-dir /path/to/aicase --device-id 401 --shop-id 146 --h5-origin http://192.168.1.20:4174
```

本地数据库首次复制后使用独立副本，打印价格在副本中设为 0，库存为保存的快照。原数据库、线上站点和供应商打包命令保持原用途。不要使用线上 H5 下单来测试这个本地副本；它们不共享订单。

`dev:mock` 仍是固定数据／日志回放；`dev:direct` 才是手机页面与后端真实交互、硬件模拟。此次直连入口不进入供应商生产资源。详细隔离与后端接口说明见后端仓库 `docs/direct-terminal-debug.md`。
